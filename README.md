# SecDrill — セキュリティ演習場

友人と合意のうえで、セキュリティの**設計・実装の理解**を競うための、完全に独立した模擬の演習環境。サーバーも外部通信もなく、ブラウザの中だけで動く。実際の脆弱なシステムは作らず、脆弱性の挙動を**模擬モデル**で再現する。

## 遊び方

```bash
npm install
npm run build        # dist/ ができる
```

`dist/index.html` をダブルクリックで開く(サーバー不要)。開発中は `npm run dev`(http://127.0.0.1:5317)。

1. 課題一覧から選ぶ。左の資料(仕様・コード・ログ)を読む。
2. 攻撃型はコマンドを打って模擬システムを操作、防御型はポリシーを書き直して提出、監査型は回答を提出。
3. クリアすると得点(基礎点×効率×ヒント係数)。操作はすべてログに残る。
4. 友達と競うには、課題画面で**同じシード**を指定して解き、「対戦・スコア」から結果ファイルを交換する。

## 課題(8題)

| 領域 | 課題 | 種類 | 難度 |
|---|---|---|---|
| 認可 | 取り消したはずの共有(認可の不統一) | 攻撃 | ★★ |
| 認可 | 請求書サービスのポリシーを直す(864通りの要件を満たす) | 防御 | ★★★ |
| セッション | 更新されない通行証(セッション固定) | 攻撃 | ★★ |
| 入力検証 | 検査と使用のあいだ(検査→変形の順序) | 攻撃 | ★★★ |
| API | 確認してから書くまで(TOCTOU、実行順序の設計) | 攻撃 | ★★★ |
| 暗号 | 一度きりのはずの値(ノンス再利用、玩具暗号) | 攻撃 | ★★★ |
| 設計 | 再設定フローの設計レビュー(欠陥と対策の対応) | 監査 | ★★ |
| ログ分析 | 夜間の持ち出し(侵入・昇格・持ち出しの復元) | 監査 | ★★★ |

どの課題も、シードで資料・IDの値・脆弱な経路が変わるので、解き方を丸暗記しても通用しない。

## 安全性

- ネットワーク通信のコードが無く、CSP も `connect-src 'none'`。ソースの検査テストで毎回確認。
- すべて模擬データ(`example.test`、`203.0.113.0/24` など予約済みのもの)。`eval`・ファイル・OS 操作は使わない。
- 他のアプリ(ajito など)のファイルには触れない。データはブラウザの localStorage だけ。
- 初期化: 課題ごと(同じ問題/別シード)・全課題・すべて消去。

## ログと不正検出

- 操作ログは各行に直前のハッシュを含む連鎖(SHA-256)。JSONL で書き出せる。
- 結果ファイルを取り込むと、連鎖の検証に加えて、**入力を模擬システムに通し直して出力が一致するか**を確かめる(解いていないのに「解けた」とした記録や、出力の書き換えを検出)。
- 割り切り: 静的アプリなのでソースを読めば正解は分かる。友人どうしの合意が前提。
